# MyHelloWorld

A simple Android "Hello World" application that demonstrates basic Jetpack Compose functionality.

## Features
- **Clock Display**: Shows the current time.
- **Interactive UI**: Tap the screen to see an emoji pop-out effect!

## Technologies Used
- **Kotlin**: The primary programming language.
- **Jetpack Compose**: For building the modern, declarative user interface.
- **Material 3**: For design components and styling.

## Installation
1. Clone this repository.
2. Open the project in Android Studio.
3. Build and run the app on an emulator or a physical device.
